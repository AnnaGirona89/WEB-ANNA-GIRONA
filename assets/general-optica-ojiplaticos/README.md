# general-optica-ojiplaticos

Coloca aquí el material de este proyecto:

- `cover.jpg` (o `cover.mp4`) — thumbnail usado en el grid de la home.
- `01.jpg`, `02.jpg`, ... — resto de material para la ficha individual (fase 2).

Mientras no exista `cover.jpg`/`cover.mp4`, la web muestra automáticamente un
placeholder gris con el nombre del proyecto; en cuanto subas el archivo con
ese nombre exacto, se sustituye solo, sin tocar código.
